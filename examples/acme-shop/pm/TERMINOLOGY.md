# Terminology

| Term | Meaning | Not to be confused with |
|---|---|---|
| Seller | A business that lists products on Acme Shop and receives payouts. | Buyer, Staff |
| Buyer | A shopper who places orders. | Seller |
| Staff | An Acme employee using the Admin console. Roles: **Admin**, **Support**. | Seller |
| Admin | Staff role with full rights, including suspending Sellers. | Support |
| Support | Staff role that can view Sellers and retry failed payouts, nothing else. | Admin |
| Payout | Money Acme sends a Seller for completed orders. Statuses shown to users: **Pending**, **Processing**, **Paid**, **Failed**. | Refund |
| Payout run | The weekly batch that sends all due Payouts. | |
| Suspended | A Seller whose shop is hidden and who can't sign in. | Paused, Disabled |
| Admin console | The Staff-facing web app. | Seller dashboard |
| Seller dashboard | The Seller-facing web app. | Admin console |
